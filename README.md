# zairuilab Homebrew Tap

Official Homebrew Cask distribution for [DueStatus Bar](https://zhizhuzairui.com/duestatus-bar/).

The install command will be enabled after the first Developer ID signed and
Apple-notarized release passes a clean installation test:

```bash
brew install --cask zairuilab/tap/duestatus-bar
```

The application source repository is maintained separately. This repository
contains only the Homebrew Cask and signed release artifacts.

The Cask metadata in this tap is MIT-licensed. DueStatus Bar itself retains its
Apache-2.0 license, upstream attribution, and modification notice inside the app
bundle.
